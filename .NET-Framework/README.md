# Biblioteca de cálculo com .NET Framework

Neste exemplo eu pratico a organização de uma biblioteca C# compatível com projetos .NET Framework. A classe calcula um resumo de valores e rejeita uma coleção vazia.

## Arquivo

`Calculator.cs` contém a implementação independente da interface de usuário. A pasta pode ser aberta em uma solução criada no Visual Studio com o framework disponível na máquina.

## O que pratiquei

- Estruturação de uma classe reutilizável
- Validação de argumentos
- Separação entre regra de negócio e aplicação

O repositório guarda o código-fonte; a compilação depende da versão do .NET Framework instalada.
