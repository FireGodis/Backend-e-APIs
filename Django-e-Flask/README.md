# Django e Flask

Nesta pasta eu comparo duas abordagens de desenvolvimento web em Python e mantenho um endpoint de saúde em cada framework.

- [Django](Django/README.md): view que retorna JSON.
- [Flask](Flask/README.md): rota `GET /health` com resposta JSON.

Instalação inicial: `python -m pip install django flask`. Os exemplos devem ser adicionados a projetos de cada framework para execução local.
