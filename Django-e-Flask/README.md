# Comparação de Django e Flask

Nesta pasta eu reúno dois pontos de partida para comparar frameworks web Python. O Django é adequado quando quero convenções e componentes integrados; o Flask permite começar com uma aplicação menor e escolher extensões conforme a necessidade.

## Exercício

1. Crie ambientes virtuais separados para Django e Flask.
2. Implemente em cada framework uma rota `GET /health` que responda JSON com `{"status":"ok"}`.
3. Compare configuração, roteamento e organização de testes.

## Instalação inicial

```bash
python -m pip install django flask
```

Este README descreve o roteiro comparativo; não afirma que os dois serviços já estão implantados.
